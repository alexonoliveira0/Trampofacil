# TrampoFácil - Plataforma de Serviços & Orçamentos

Plataforma completa de trabalho autônomo com suporte a PIX BACEN, taxa de cliente, mensalidade de prestador e painel administrativo.

## Publicação na Vercel
1. Certifique-se de que todos os nomes dos arquivos e diretórios estão em inglês e na estrutura padrão do Next.js App Router (conforme este pacote).
2. Conecte seu repositório GitHub na Vercel.
3. Clique em **Deploy**.
